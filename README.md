# Loja de Roupas

Projeto acadêmico da Faculdade Senac Pernambuco, curso de Análise e
Desenvolvimento de Sistemas, 4º módulo, disciplina Coding, semestre 2026.2.

Professor: Sebastião Rogério. Aluno: Ítalo Rodrigues Pereira.

Implementação própria das aulas 08 a 13, desenvolvida com assistência de IA
(Codex). Os PDFs da disciplina orientam os requisitos; o gabarito não foi consultado.

Crie o ambiente com `python -m venv .venv`, ative com
`.venv\Scripts\Activate.ps1` e instale com `pip install -r requirements.txt`.
Os testes são executados com `pytest`.
